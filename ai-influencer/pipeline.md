# AIキャラクター動画・投稿下書きの制作指示書（M2・8GB Mac 版／1,000円以下の日用雑貨）

教材「AIインフルエンサーの教科書」第6章 6-6 の形式に沿い、ローカルで SDXL / LTX-Video を動かせない環境向けに置き換えたもの。

## 前提
- 作業場所: ~/ai-influencer/
- character.md と products/today.md を読む。
- 基準画像: assets/reference_face.png（台帳に記録した版）
- 画像→動画は外部サービスで行う。手元ではナレーション・BGM・字幕・結合・検査だけを行う。
- 既存の出力先や実行記録を削除しない。2本目以降は未使用の out-dir を使う。
- 外部サービスへ送る生成依頼は1件ずつ。重複送信しない（課金が発生するため、送る前に件数と費用を報告する）。

## 実行
1. products/today.md から、今日の商品3つ・台本・PRの有無を確認する。
2. scripts/heygen_video.py で、基準画像に products/today.txt の台本をしゃべらせる（plan → submit → wait → collect）。
   - 冒頭のつかみと締めの2本に分けてもよい。submit は1件ずつ、送る前に件数と費用を報告する。
3. 全編を確認し、顔・口・手が崩れたものは使わない。
4. 商品カット（商品画像＋名前・価格・字幕）を3枚用意する。人物が商品を持つ合成はしない。
5. 構成（約20秒・720×1280）: 人物（つかみ）→ 商品カット1〜3 → 人物（締め）。全区間に「AI生成」「PR」、最後に「価格は投稿時点のものです」。
6. 映像・音声を最後までデコードして検査する（ffprobe / ffmpeg -xerror）。
7. 最後まで再生して、映像・声・BGM・字幕・表示を確認する。
8. 同じフォルダに post_draft.txt（タイトル・説明文・ハッシュタグ・表示の設定メモ）を保存する。

## 完了条件
- 声・BGM・字幕付きの MP4、投稿文、検査結果がそろう。
- 投稿文に、架空の体験や結果の断定がない。
- 公開・予約投稿は行わない（人が確認して手動で公開する）。
