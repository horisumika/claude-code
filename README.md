# 行政書士業務システム スマホ対応

保利澄香行政書士事務所の業務システムを、スマートフォンでも快適に操作できるようにする（レスポンシブ対応する）ための **指示書** をまとめたリポジトリです。

## 対象システム

| システム | 用途 | URL |
|---|---|---|
| 業務管理システム | 契約内容の確認・単発業務の登録・請求書作成 | hori-office-system.vercel.app |
| 告訴状作成システム | 告訴状作成・テンプレ・警察タスク・ステータス管理 | line-reply-admin.vercel.app/admin/complaints |

※ kishigami-law.jp は今回の対象外。

## コードの置き場所（2026-08-18 更新）

| システム | ソースコードの場所 | クラウドの Claude から |
|---|---|---|
| 業務管理システム | Mac ＋ GitHub `horisumika/hori-office-system-clean`（非公開） | **触れる** |
| 告訴状作成システム | Mac のみ | 触れない |

業務管理システムは GitHub の非公開リポジトリに上がっているため、**ブラウザ／スマホから使うクラウドの Claude でもコードを読んで直せます**（接続・ビルド確認済み）。ただし本番の Vercel へのデプロイは、これまでどおり Mac 側から行います。

告訴状作成システムはまだ Mac の中だけにあります。同じようにクラウドから触れるようにする手順は [`docs/クラウドClaudeから業務システムを触れるようにする.md`](docs/クラウドClaudeから業務システムを触れるようにする.md) にまとめてあります。

## なぜ「指示書」なのか

スマホ対応の改修そのものは、ビルド確認から Vercel への反映までを一気に行える **Mac 上の Claude Code** に任せるのが最短です。そのため、この下の使い方では貼り付け用のプロンプトを用意しています。

## 使い方（かんたん3ステップ）

1. お使いの Mac で、いつもシステムを触っている Claude Code を開く
2. [`docs/スマホ対応-指示書.md`](docs/スマホ対応-指示書.md) の中の「貼り付け用プロンプト」を、まるごとコピーして貼り付ける
3. Claude Code が改修 → ビルド確認 → Vercel へデプロイまで実行します

## 安全上の注意

- 引き継ぎ資料に載っていたログインパスワードや依頼者の個人情報は、このリポジトリには一切含めていません。
- 今回の改修は「見た目・レイアウト（スマホ表示）」のみ。ログイン認証やアクセス制限のしくみは変更しません。
