# ネットの誹謗中傷、「名誉毀損」と「侮辱」はどう違う？──厳罰化から3年、被害に遭ったときにできること

> 掲載先：事務所HP コラム／想定カテゴリ：ネット誹謗中傷・告訴状作成
> 執筆：保利澄香行政書士事務所
> 記載内容は公表資料（法務省・総務省・e-Gov法令）に基づきます。最終確認日は公開前に更新してください。

SNSやレビューサイトに、身に覚えのないことを書かれた。名前を出して笑いものにされた。
「これって犯罪になるんですか？」というご相談を、当事務所でも数多くお受けします。

答えから言うと、**なることがあります**。ただし「名誉毀損罪」と「侮辱罪」は別の犯罪で、成立する条件も、その後の動き方も違います。しかも被害者側には**6か月という期限**があります。ここを知らないまま時間が過ぎてしまうケースが、本当に多いのです。

このコラムでは、条文と公的な資料をもとに、違いと初動を整理します。

## 1. 一番の違いは「事実を摘示したかどうか」

ざっくり言うと、こうです。

| | 名誉毀損罪（刑法230条） | 侮辱罪（刑法231条） |
|---|---|---|
| 中身 | 具体的な事実を示して社会的評価を下げる | 事実を示さず、公然と人を軽蔑する表示をする |
| 例 | 「〇〇は不倫している」「前科がある」 | 「ブス」「バカ」 |
| 法定刑 | 3年以下の拘禁刑または50万円以下の罰金 | 1年以下の拘禁刑もしくは30万円以下の罰金、または拘留もしくは科料 |
| 公訴時効 | 3年 | 3年 |

条文そのものを見てみましょう。

> **刑法230条1項**
> 公然と事実を摘示し、人の名誉を毀損した者は、その事実の有無にかかわらず、3年以下の拘禁刑又は50万円以下の罰金に処する。

ポイントは太字にしたいところですが、**「その事実の有無にかかわらず」**の一言です。
つまり、**書かれた内容が本当かどうかは、原則として関係ありません**。「事実なんだから何が悪い」は、そのままでは通らないということです（例外は後述の3.）。

一方の侮辱罪。

> **刑法231条**
> 事実を摘示しなくても、公然と人を侮辱した者は、1年以下の拘禁刑若しくは30万円以下の罰金又は拘留若しくは科料に処する。

「事実を摘示しなくても」。ここが名誉毀損罪との分かれ目です。中身のない罵倒でも犯罪になり得る、ということですね。

なお、亡くなった方に対する名誉毀損は、**虚偽の事実**を示した場合でなければ罰せられません（刑法230条2項）。

## 2. 「公然と」はSNSならほぼ当てはまります

どちらの罪にも共通する要件が「公然と」です。これは**不特定または多数の人が認識できる状態**を指します。

SNS・掲示板・レビューサイトへの投稿は、原則としてこれに当たります。フォロワーの多い少ないにかかわらず、誰でも見られる状態で書いた時点で「公然と」の要件は満たしやすい、と考えてよいでしょう。

> 補足：「鍵アカウントやグループチャットなら大丈夫？」「ハンドルネームへの中傷は？」というご質問もよくいただきます。裁判例の考え方としては、特定少数への発信でも不特定・多数へ広がる可能性があれば公然性を認める、ハンドルネームでも周辺情報から本人を特定できれば成立し得る、と一般に説明されています。個別の判断は事案によりますので、実際のケースは資料をお持ちのうえご相談ください。

## 3. 正当な批判まで処罰されるわけではありません

ここは誤解されがちなところです。刑法には、こういう規定があります。

> **刑法230条の2第1項（要旨）**
> その行為が**公共の利害に関する事実**に係り、かつ、その目的が**専ら公益を図ること**にあったと認める場合には、事実の**真実であることの証明**があったときは、罰しない。

つまり、①公共性、②公益目的、③真実性の証明、この3つがそろえば処罰されません。公務員や公選の候補者に関する事実についても、同様の特例が置かれています（同条3項）。

侮辱罪の厳罰化にあたっても、法務省のQ&Aでは、**正当な言論・批判活動は処罰の対象とならない**こと（表現の自由への配慮）が繰り返し説明されています。

サービスへの正直な感想や、公的な立場にある人への批判と、個人を狙い撃ちにした誹謗中傷。この線引きの根拠が、この条文だとお考えください。

## 4. 侮辱罪の厳罰化から3年──国の「答え合わせ」が出ました

侮辱罪の法定刑は、令和4年の法改正（令和4年法律第67号、同年7月7日施行）で引き上げられました。それまでの「拘留または科料」だけから、懲役・禁錮・罰金が加わり、その後の拘禁刑の創設（令和7年6月1日施行）を経て、現在は**1年以下の拘禁刑もしくは30万円以下の罰金、または拘留もしくは科料**となっています。

この改正には効果がありました。特に大きいのが、**公訴時効が1年から3年に伸びた**ことです。ネットの被害は気づくのが遅れがちなので、実務上ここは非常に重要です。

そして改正法の附則で「施行から3年経過時の検証」が定められていたことから、法務省に「侮辱罪の施行状況に関する刑事検討会」が設けられ、**令和8年2月に取りまとめが公表**されました。報道されている骨子は、次のようなものです。

- 施行後、ネット上の行為に侮辱罪が適用され、2025年6月末までに罰金または科料が確定したのは**104人**（法務省調べ）
- 悪質な事案に適切に対処できるようになるなど、ネット中傷対策として**一定の効果があった**と評価
- 現時点で**適用対象の拡大などの法改正は必要ない**とする一方、ネット上の誹謗中傷は「**憂慮すべき状況にある**」と指摘
- 政府に対し、刑事上の対策を不断に検討し、臨機に対応することを求めた
- 警察において**侮辱罪での現行犯逮捕の事例はなく**、適正な運用が行われている旨の説明があった

「厳罰化されたのに、たった104人？」と受け取るか、「104人も確定している」と受け取るかは、立場によって分かれるところでしょう。ただ、検討会に提出された事例集を見ると、**科料9,900円から罰金30万円まで**の処罰例が並んでいます。「捕まらないだろう」と書き込んだ一言に、前科がつくということです。

## 5. 見落とすと取り返しがつかない「6か月」

名誉毀損罪も侮辱罪も、**親告罪**です（刑法232条）。被害者の告訴がなければ、検察官は起訴できません。

そして、告訴には期限があります。

> **刑事訴訟法235条**
> 親告罪の告訴は、**犯人を知った日から6か月**を経過したときは、することができない。

「犯人を知った日から」です。相手が誰か分からない状態が続いているうちは進行しない、という理解が一般的ですが、では相手が判明した瞬間から6か月のカウントダウンが始まる、ということでもあります。

さらに厄介なのが、**通信ログの保存期間**です。投稿者を特定するには、サイト運営者やプロバイダに残っている記録をたどる必要がありますが、記録は永久には残りません。**気づいた時点で動き始める**ことが、そのまま結果を左右します。

告訴の方法自体はシンプルで、書面または口頭で、検察官または司法警察員に対して行います（刑事訴訟法241条）。当事務所では、この**告訴状の作成**をお手伝いしています。

> **「投稿者が分からないから、警察は受けてくれないのでは？」**
> よくあるご不安ですが、犯罪捜査規範63条は、警察官は告訴・告発をする者があったときは、**管轄区域内の事件であるかどうかを問わず受理しなければならない**旨を定めています（要旨）。「相手が特定できていない」「管轄が違う」を理由に門前払いされるいわれはありません。当事務所では、受理していただけるよう、**告訴状にこうした点を踏まえた記載をしています**。

## 6. 削除だけなら、ご自身でもできます

「犯人を捕まえたいわけじゃない。とにかく消したい」。これも切実なご要望です。

実は、**法務省が削除依頼のための資料を無料で公開しています**。

- インターネット上の誹謗中傷 書き込み削除依頼の手引き（令和7年度版）
  https://www.moj.go.jp/content/001458241.pdf
- 削除依頼メールのテンプレート（Word）
  https://www.moj.go.jp/content/001458242.docx
- 侵害情報の通知書 兼 送信防止措置依頼書（見本・記載例）
  https://www.moj.go.jp/content/001243953.pdf

ご自身での依頼が難しい場合は、**法務局（人権擁護機関）**に相談するという選択肢があります。法務局は、削除依頼の方法を助言する「援助」のほか、違法性を判断したうえでプロバイダに削除を求める「**要請**」まで行います。

法務省の統計（令和7年）を見ると、インターネット上の人権侵害情報として新規に救済手続が始まったのは**1,569件**。処理の内訳では、援助が約4割、法務局からプロバイダへの削除要請が**349件**（約2割）でした。決して珍しい手続きではない、ということです。

なお、内容の内訳は、プライバシー侵害503件・識別情報の摘示494件・名誉毀損348件で、この3類型が全体の85%を占めています。

ただし、**法務局は発信者情報開示請求の代行まではできません**。そこは弁護士の領域になります（後述の8.）。

## 7. プラットフォーム側の義務も強化されました

2025年4月1日、これまでの「プロバイダ責任制限法」が**情報流通プラットフォーム対処法**（情プラ法）に生まれ変わりました。

大きな柱は、一定規模以上の大規模プラットフォーム事業者に対する、**①削除対応の迅速化**と**②運用の透明化**の義務付けです。具体的には、削除申出の窓口と手続を整備・公表すること、専門の調査担当者を置くなど体制を整えること、申出に対して**期間内に判断して申出者へ結果を通知**すること、削除の基準を分かりやすく公表すること、削除した場合は発信者にも通知すること、そして年1回、対応状況を公表することなどが求められます。

指定を受けた事業者は**9社**。X、Google（YouTube）、Meta（Facebook・Instagram・Threads）、TikTok、LINEヤフー、ドワンゴ（ニコニコ）、サイバーエージェント（Amebaブログ）、爆サイ.com運営会社、Pinterestです。日常的に使われている主要なサービスは、ほぼ対象と考えてよいでしょう。

「送っても無視される」時代から、「窓口と期限がある」時代へ。削除依頼のハードルは、確実に下がっています。

## 8. 「相手を特定して損害賠償を」という段階になったら

投稿者を特定する手続きが、**発信者情報開示請求**です。情プラ法5条により、①権利が侵害されたことが明らかであること、②開示を受けるべき正当な理由があること、を満たす場合に、氏名・住所・メールアドレス等の開示を請求できます。

令和3年の改正で創設された**発信者情報開示命令**（令和4年10月施行）により、従来はコンテンツプロバイダ・アクセスプロバイダの2段階に分けて行う必要があった裁判手続を、1つの非訟手続でまとめて行えるようになりました。あわせて、**提供命令**（15条）・**消去禁止命令**（16条）によって、消えてしまいがちなログを保全することもできます。

ここで正直にお伝えしておくと、**開示請求の要件は削除請求より厳しい**とされています（「権利侵害の明白性」が求められるためです）。そして、**開示請求や損害賠償請求の代理は、弁護士の業務**です。当事務所では、告訴状などの書類作成でお力になれる範囲と、弁護士におつなぎすべき範囲を、最初にはっきりお伝えするようにしています。

ちなみに、実務の感覚として、国内サイトが相手であれば開示請求をしなくても告訴状の受理まで進みやすい一方、XやInstagramなどの海外サービスが相手の場合は、開示請求をしないと受理後も被疑者が特定されず、警察から開示請求を勧められることが多い、という違いがあります。

なお刑事とは別に、民事上は**不法行為**（民法709条・710条）として、損害賠償請求や削除請求の対象にもなります。

## 10. 当事務所ができること

当事務所では、ネット上の誹謗中傷について、**告訴状の作成**を中心にお手伝いしています。

- 証拠の残し方（スクリーンショット・URL・日時の記録）
- 告訴状に記載する事実の整理（いつ・どこに・何を書かれ、いつそれを知ったか）
- 告訴状の作成と、警察へ持ち込む際の資料の組み立て
- 法務省が公開している手引き・テンプレートのご案内（削除依頼の代行は行っておりません）

一方で、**発信者情報開示請求や損害賠償請求の代理、示談交渉、捜査機関との交渉は弁護士の業務**です。必要な場合は、その旨をお伝えし、弁護士におつなぎします。

「これって書かれ損なんでしょうか」と諦めてしまう前に、**告訴状の作成についてご相談ください**。時間の勝負になる部分がありますので、**早いほど選べる手段が多い**、これだけは覚えておいていただければと思います。
