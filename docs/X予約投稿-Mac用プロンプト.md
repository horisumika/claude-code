# X予約投稿 指示書（Mac 側の Claude Code に貼るだけ）

クラウド側のこのセッションからは、Mac で開いている Chrome を操作できません（別マシンのため）。
Chrome の操作は、いつもシステムを触っている **Mac 上の Claude Code** に任せてください。

下の「===」で囲まれた中を、まるごとコピーして貼り付けます。
投稿する本文は `docs/X投稿-名誉毀損と侮辱の違い.md` のA案（長文1本）と同じものです。

---

## 貼り付け用プロンプト

```
=======================================================================
Chrome を操作して、X（旧Twitter）の予約投稿を1件セットしてほしい。
アカウントは Premium なので長文投稿が使える。

【ゴール】
下記の本文を、2026年8月17日（月）12:15（JST）に予約投稿する状態にする。
※「ポストする」ボタンは絶対に押さないこと。誤爆すると即時投稿になる。
　予約設定の確定ボタン（「予約設定」/「Schedule」）だけを押す。

【手順】
1. まず本文をクリップボードに入れる。長文かつ改行を多く含むので、
   キーボード入力ではなくクリップボード経由で貼るのが確実。
   本文をヒアドキュメント（クォート付き）で pbcopy に渡すこと。
   本文はこのリポジトリの docs/X投稿-名誉毀損と侮辱の違い.md のA案、
   コードブロックの中身をそのまま使う。
   「（コラムURL）」の行は、コラムがHPに公開済みならURLに置換、
   未公開ならその2行（▼の行と合わせて）を削除する。判断がつかなければ
   先に自分に確認すること。

2. Chrome にプログラムから接続できるようにする。
   すでに開いている Chrome には後から接続できないので、いったん終了して
   リモートデバッグを有効にして起動し直す。プロファイルは同じものを使う
   ので、X のログイン状態は維持される。

   osascript -e 'quit app "Google Chrome"'
   sleep 2
   open -a "Google Chrome" --args --remote-debugging-port=9222
   sleep 3

   ※終了前に、入力途中で保存していないタブがないか一応確認すること。

3. Playwright で CDP 接続する（未インストールなら npm i -D playwright。
   ブラウザ本体のダウンロードは不要）。

   const b = await chromium.connectOverCDP('http://127.0.0.1:9222');
   const ctx = b.contexts()[0];
   const page = await ctx.newPage();
   await page.goto('https://x.com/compose/post');

4. ログイン済みか確認する。ログイン画面が出たら、そこで作業を止めて
   自分に知らせること（パスワードは扱わない）。

5. 本文を入力する。入力欄は data-testid="tweetTextarea_0" が目印。
   見つからなければ role や aria-label で探し直す。
   入力欄をクリックしてフォーカスしてから Cmd+V で貼る。
   改行が送信扱いにならないよう、Enter は押さない。

6. 入力後、必ずスクリーンショットを撮って、本文が最後まで（改行と
   URLも含めて）入っているか目視確認する。長文なのでスクロールして
   末尾まで確認すること。

7. 予約設定を開く。ツールバーのカレンダーアイコン（aria-label に
   「予約」や「Schedule」を含むボタン）を押す。
   ダイアログで 2026年8月17日 12:15 を選び、「確認」→「予約設定」。
   ※日付ピッカーの構造は変わりやすいので、素直に取れなければ
   　DOM を調べて対応すること。

8. 完了後にスクリーンショットを撮り、予約一覧
   （https://x.com/compose/post/unsent/scheduled ）を開いて
   1件登録されていることを確認して報告する。

【うまくいかないとき】
セレクタが見つからない、ピッカーが操作できない等で3回試して駄目なら、
無理に押し進めず「本文を入力した状態」で止めて、その旨を報告すること。
本文はクリップボードにも入っているので、あとは自分が
カレンダーアイコン → 日時指定 → 予約設定、と押せば済む。
=======================================================================
```

## 手でやる場合（1分で終わります）

自動化にこだわらないなら、こちらが確実です。

1. Xの投稿画面に、A案の本文を貼る（`docs/X投稿-名誉毀損と侮辱の違い.md`）
2. ツールバーの**カレンダーアイコン**をクリック
3. 「2026年8月17日 12:15」を指定して「確認」
4. 「**予約設定**」をクリック（「ポストする」ではありません）

投稿日時にはカレンダーのリマインダー（本文入り）も入れてあるので、当日その通知からコピペしても間に合います。
