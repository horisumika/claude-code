# X投稿ストック｜ネット誹謗中傷シリーズ（長文9本）

内部リファレンス「ネット上の誹謗中傷（名誉毀損・侮辱）公的資料まとめ」の切り口メモをもとにした投稿ストックです。
Premiumアカウント（長文可）前提で、**すべて長文・具体例つき**。短文の煽り投稿は入れていません。

**具体例の出どころは3種類**あり、投稿ごとに末尾へ明記しています。

- **公表資料の実例**：法務省広報誌の適用例、人権擁護機関の救済事例など（出典URLあり）
- **統計の実数**：件数・金額など、公表資料に載っている数字
- **想定例**：「〇〇は不倫している」のような、説明のための架空の書き込み例（実在の事案ではありません）

全文について**非弁チェック済み**です（`docs/非弁チェック-記事とX投稿.md`）。個別事案の当否を断定しない、相談には必ず「告訴状の作成について」と目的語を付ける、代理・交渉の主語を事務所にしない、というルールで統一しています。

## 2｜削除依頼は自分でできる（8/20）

```
「犯人を捕まえたいわけじゃない。とにかく消したい」

ご相談でいちばん多いのが、これです。

そして実は、削除依頼のための道具は、法務省がすべて無料で公開しています。あまり知られていないので紹介させてください。

■ ダウンロードして使えるもの

書き込み削除依頼の手引き（令和7年度版）
https://www.moj.go.jp/content/001458241.pdf

削除依頼メールのテンプレート（Word）
https://www.moj.go.jp/content/001458242.docx

侵害情報の通知書 兼 送信防止措置依頼書（記載例つき）
https://www.moj.go.jp/content/001243953.pdf

テンプレートを埋めて送る。それだけで動く事案は、実際にあります。

■ 実際にどんなものが消えているのか

法務省の令和7年の救済事例を見ると、たとえばこういうものが並んでいます。

・ヤミ金の利用者情報を晒すサイトに、名前や連絡先を掲載された
・SNSに、無断で撮影された写真と侮辱的な文言を一緒に投稿された
・地図サービスのクチコミ欄に、自分が写った写真を無断で掲載された
・元交際相手に、私的な画像を投稿された

いずれも法務局の削除要請等によって、削除に至っています。
https://www.moj.go.jp/content/001458953.pdf

「こんなことで動いてもらえるのか」と思うようなものが、ちゃんと対象になっています。

■ 自分で書くのが難しいときは

みんなの人権110番（法務局）
0570-003-110

インターネット人権相談受付窓口
https://www.jinken.go.jp/

法務局は2段構えで動きます。ひとつは、削除依頼のやり方を教えてくれる「援助」。もうひとつは、法務局自身が違法性を判断して、プロバイダに削除を求める「要請」です。

令和7年は、処理のうち援助が約4割、要請が349件でした。珍しい手続きではありません。

■ できないこともあります

法務局は、発信者情報開示請求の代行まではしません。そこは弁護士の領域です。

当事務所も削除依頼の代行は行っておらず、告訴状の作成を中心にお手伝いしています。「消したい」のか「相手を特定して責任を問いたい」のかで進む道が変わるので、最初に整理しておくと迷いません。
```

> 具体例：公表資料の実例（令和7年の救済事例）／統計の実数（349件・約4割）
> ※救済事例は原典（001458953.pdf）に沿って要約。特定の個人が想起される書き方にはしていません

## 3｜6か月の期限と、量刑のリアル（8/24）

```
ネット中傷のご相談で、いちばん多い後悔がこれです。

「もっと早く動けばよかった」

■ 期限は「犯人を知った日から6か月」

名誉毀損罪も侮辱罪も親告罪です。被害者の告訴がなければ、検察官は起訴できません（刑法232条）。

そして告訴ができるのは、犯人を知った日から6か月（刑事訴訟法235条）。

「犯人を知った日から」なので、相手が誰か分からないうちは進みません。裏を返せば、相手が判明した瞬間にカウントダウンが始まるということです。

さらに、投稿者をたどるには通信ログが必要ですが、これも永久には残りません。制度の期限と、記録が消えるまでの時間。二重の締め切りがあります。

■ 実際、いくら取られるのか

厳罰化のあとに裁判が確定した事案を集めた法務省の事例集には、科料9,900円から罰金30万円までの処罰例が並んでいます。

金額だけ見ると軽く感じるかもしれません。でも、科料も罰金も刑罰です。

そして令和4年の改正で、公訴時効が1年から3年に伸びました。実務でいちばん効いているのは、この2年の差だと感じています。ネットの被害は気づくのが遅れるので、以前は「気づいたときには終わっていた」ことが本当に多かったのです。

■ つらいときに、これだけは

動く気力がないときでも、スクリーンショットだけは取っておいてください。

投稿の画面、URL、日付。この3つがそろっているかどうかで、後からできることの幅が変わります。判断はその後で構いません。

告訴状の作成についてのご相談は、当事務所でお受けしています。
```

> 具体例：統計の実数（科料9,900円〜罰金30万円、時効1年→3年）
> ※個別事例は事例集の原典（https://www.moj.go.jp/content/001446562.pdf ）で確認してから

## 4｜IP不明でも告訴は門前払いされない（8/27）

```
「相手が誰か分からないと、警察は受けてくれませんよ」

そう言われて諦めてしまった方に、何人もお会いしました。でも、条文はそうなっていません。

■ 条文に書いてあること

告訴は、書面または口頭で、検察官または司法警察員に対して行います（刑事訴訟法241条）。ここに「被疑者が特定されていること」という条件はありません。

そして犯罪捜査規範63条は、警察官は告訴・告発をする者があったときは、管轄区域内の事件であるかどうかを問わず受理しなければならない、と定めています（要旨）。

「IPが分からないから」「うちの管轄じゃないから」。これらは、それ自体では受理を断る理由になりません。

■ ただし、相手のサービス次第で道のりは変わります

ここは正直にお伝えします。

国内のサイトが相手なら、開示請求をしていなくても、告訴状の受理まで進みやすい傾向があります。

一方でXやInstagramのような海外サービスが相手だと、受理されたあとも被疑者が特定できず、警察から開示請求を勧められることが多いです。書き込まれた場所によって、必要な準備が変わるということです。

■ 何が効くのか

受理までの距離を縮めるのは、結局のところ資料です。

・投稿のスクリーンショット（URLと日付が写っているもの）
・どの投稿が、どの部分で自分を指しているのか
・いつ、どうやってそれを知ったのか（6か月の起算点になります）

これが整理されているかどうかで、話の通り方が変わります。当事務所では、受理していただけるよう、告訴状にこうした点を踏まえた記載をしています。

なお、捜査機関との交渉や、開示請求・損害賠償請求の代理は弁護士の業務です。当事務所がお手伝いするのは、告訴状などの書類の作成です。

「門前払いされそうで怖い」という段階でも、書類の作り方からご相談いただけます。
```

> 具体例：国内サイトと海外サイトの実務上の違い（事務所の実務経験）
> ※非弁チェック済み。「対応します」ではなく「告訴状に記載します」という書き方に統一しています

## 5｜正当な批判と誹謗中傷の線引き（8/31）

```
「批判したら訴えられるんですか？」

厳罰化のニュースが出るたびに、この不安をよく聞きます。答えは、いいえです。

■ 条文に例外が書いてあります

刑法230条の2は、①公共の利害に関する事実に係り、②その目的が専ら公益を図ることにあり、③真実であることの証明があったときは、罰しない、と定めています。

公務員や、公選による公務員の候補者に関する事実についても、真実性の証明があれば罰しない、という規定が置かれています（同条3項）。

侮辱罪の厳罰化のときも、法務省のQ&Aで、正当な言論・批判活動は処罰の対象とならないことが繰り返し説明されていました。表現の自由への配慮です。
https://www.moj.go.jp/keiji1/keiji12_00194.html

■ では、実際にどこで分かれたのか

法務省の広報誌に、侮辱罪の過去の適用例が紹介されています。

駅の柱に「ご注意 ○○ 悪質リフォーム工事業者です」と書いた紙片を貼った、という事案です。
https://www.moj.go.jp/KANBOU/KOHOSHI/no78/8.html

これ、本人の中ではおそらく「告発」だったはずです。悪質な業者から他の人を守ろうとした、という気持ちもあったかもしれません。それでも、侮辱として扱われました。

告発のつもりでも、やり方を誤ると自分が加害者の側に回る。ここが本当に難しいところです。

■ 書く前に確かめる3つ

・事実を書こうとしているのか、評価をぶつけようとしているのか
・その事実を裏づける資料が、いま手元にあるか
・目的は、みんなに知らせることか、それとも相手を貶めることか

たとえば「あの店の対応が遅くて、料理も冷めていた」は前者に寄ります。一方で、店主個人の容姿や人格を持ち出した瞬間、話は変わります。

この3つを自分に確認するだけで、たいてい線は見えてきます。
```

> 具体例：公表資料の実例（法務省広報誌の適用例）／想定例（飲食店レビュー）
> ※適用例は広報誌の記載どおり。事案の当否についての評価は加えていません

## 6｜情プラ法で何が変わった？（9/3）

```
2025年4月、「プロバイダ責任制限法」という名前がなくなったのをご存知でしょうか。

情報流通プラットフォーム対処法、略して情プラ法。名前だけでなく、中身がかなり変わりました。

■ 大手プラットフォームに義務が入りました

一定規模以上の事業者に、①削除対応の迅速化、②運用の透明化が義務付けられています。具体的には、

・削除申出の窓口と手続を整備して公表する
・侵害情報の調査を担当する専門員を置くなど、体制を整える
・申出に対して期間内に判断し、申出者に結果を通知する
・削除の基準を、法律用語だけでなく分かりやすい日本語で公表する
・削除したときは、発信者にも通知する
・対応状況を年1回公表する

「送っても返事すら来ない」が、制度上は許されなくなったということです。

■ 指定されたのは、この9社

X／Google（YouTube）／Meta（Facebook・Instagram・Threads）／TikTok／LINEヤフー（Yahoo!知恵袋・LINEオープンチャット・LINE VOOMなど）／ドワンゴ（ニコニコ）／サイバーエージェント（Amebaブログ）／爆サイ.com運営会社／Pinterest

匿名掲示板から大手SNSまで、実際に相談の多い場所がひととおり入っています。

各社の窓口とルールは、総務省が一覧にまとめています。
https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/ihoyugai.html

■ 使う側として、何が変わるか

削除依頼は「お願い」ではなく、応答義務のある手続きになりました。

だからこそ、窓口の場所を知っていることと、書式が整っていることの価値が上がっています。法務省の手引きとテンプレートは無料で使えますので、あわせてどうぞ。
https://www.moj.go.jp/content/001458241.pdf
```

> 具体例：指定9社の実名（公表資料）
> ※通知までの日数（施行規則で規定）は本文に入れていません。入れる場合は e-Gov（https://laws.e-gov.go.jp/law/504M60000008039 ）で確認してから

## 7｜統計で見るネット中傷（9/7）

```
「ネットの中傷って、実際どのくらい起きているんですか？」

法務省の人権擁護機関が、毎年数字を出しています。令和7年分を見てみます。
https://www.moj.go.jp/content/001458953.pdf

■ インターネット上の人権侵害情報：新規1,569件

前年から138件減りました。ただ、喜べる数字ではありません。この10年、おおむね1,600〜2,200件のあいだで高止まりしています。

しかもこの件数は、プロバイダへの削除要請の件数ベース。100件の投稿をまとめて1回要請すれば「1件」と数えられます。実際に書かれた数は、この何倍もあるということです。

■ 内訳の85%は、たった3つ

・プライバシー侵害　503件
・識別情報の摘示　494件
・名誉毀損　348件

この3つで全体の85%を占めます。

注目したいのが2番目の「識別情報の摘示」。同和地区の指摘などがこれにあたります。平成28年には26件でした。それが令和7年は494件です。

10年で、けた違いに増えています。

■ 数字の向こう側

同じ資料には、実際に救済された事例も載っています。

・ヤミ金の利用者情報を晒すサイトへの掲載
・SNSでの無断撮影＋侮辱的な文言の投稿
・地図サービスのクチコミ欄への無断写真掲載
・元交際相手による私的画像の投稿

いずれも法務局の削除要請等で、削除に至っています。

■ そして、相談は年15万件超

人権相談は年152,918件。電話が61.1%、面接が14.4%、チャットが9.7%。

チャットで相談できるようになったことは、素直に良い変化だと思います。声を出さなくても届けられる窓口が増えるのは、それだけで救われる人がいます。

数字は「自分だけじゃない」と教えてくれます。ひとりで抱えないでください。
```

> 具体例：統計の実数（1,569件・3類型85%・26件→494件・152,918件）／公表資料の救済事例
> ※2026/8/13の円グラフ投稿と数字が重複しないか確認を。折れ線グラフの素材にしやすい回です

## 8｜開示命令とログの保全（9/10）

```
「相手を特定して、責任を取ってもらいたい」

その段階に進むと、発信者情報開示請求という手続きになります。ここ数年で、かなり使いやすくなりました。

■ 求められる要件

情プラ法5条は、①権利が侵害されたことが明らかであること（権利侵害の明白性）、②開示を受けるべき正当な理由があること、この2つを満たす場合に、氏名・住所・メールアドレス等の開示を請求できると定めています。

正直に言うと、この要件は削除請求より厳しいです。「消してほしい」で足りる場面でも、開示となると「明らかに違法」まで求められます。

■ 2回だった裁判が、1つになりました

以前は、投稿先のサイト（コンテンツプロバイダ）に対して1回、そこで判明した回線業者（アクセスプロバイダ）に対してもう1回、裁判を起こす必要がありました。

その間にログが消えれば、そこで終わりです。実際、間に合わなかった事案は少なくありませんでした。

令和3年の改正で創設された発信者情報開示命令（令和4年10月施行）により、これを1つの非訟手続でまとめて行えるようになりました。

あわせて、提供命令（15条）と消去禁止命令（16条）で、消えやすいログを保全できます。ログイン時の情報の開示にも対応しています。

■ それでも、時間との勝負であることは変わりません

制度が良くなっても、記録が消えてしまえば取り返せません。

そして刑事のほうにも、犯人を知った日から6か月という告訴期間があります（刑訴235条）。

なお、開示請求や損害賠償請求の代理、示談交渉は弁護士の業務です。当事務所がお手伝いするのは告訴状などの書類作成で、開示請求が必要な場面では弁護士におつなぎしています。

迷っている時間がいちばんもったいない。それだけはお伝えしておきます。
```

> 具体例：制度改正の前後（2段階の裁判が1つの非訟手続に）
> ※非弁チェック済み。開示請求は弁護士業務である旨を本文内に明記しています
