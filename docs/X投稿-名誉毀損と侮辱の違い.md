## 1本目（予約投稿するのはこれ／266）

```
「バカ」「ブス」は侮辱罪。
「〇〇は不倫してる」は名誉毀損罪。

違いは「具体的な事実を書いたか」だけです。

しかも名誉毀損は、書いた内容が本当でも成立します。条文にはっきり「その事実の有無にかかわらず」とあります（刑法230条）。

「事実だから何が悪い」は通用しません。
```
