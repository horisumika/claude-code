# 非弁チェック｜コラム・X投稿

事務所名義で公開する原稿を、**弁護士法72条（非弁行為の禁止）**と**行政書士法1条の2・1条の3**の観点で点検した記録です。
公開前の最終確認と、今後の原稿を書くときの基準としてお使いください。

## 判断の基準にしたもの

| 論点 | 基準 |
|---|---|
| 弁護士法72条 | 報酬を得る目的で、法律事件に関して**鑑定・代理・仲裁・和解その他の法律事務**を取り扱うことを業とするのは不可 |
| 行政書士の業務範囲 | 官公署に提出する書類、権利義務・事実証明に関する書類の**作成**とその**作成に関する相談** |
| 告訴状 | 官公署（警察・検察）に提出する書類として**作成は可能**。ただし提出後の折衝・捜査機関との交渉は業務外 |
| 削除請求・開示請求 | 相手方（プロバイダ等）に対する**権利行使の代理は不可**。手続きの一般的な案内・情報提供にとどめる |
| 個別事案の当否 | 「これは名誉毀損に当たります」という**個別具体的な法的評価は鑑定にあたり得る**。一般論の提示にとどめる |

## 指摘して修正した箇所

### 1. 「この条文を根拠に対応することがあります」（コラム5節・投稿4）

- **問題**：捜査機関との折衝を事務所が代わって行う、と読める。告訴状の作成を超えた**代理**と受け取られる余地がある。
- **修正後**：「受理していただけるよう、**告訴状にこの点を踏まえた記載をしています**」——書類作成の範囲内であることが文面から分かる形に変更。

### 2. 「名誉毀損・侮辱のどちらを問題にするかの整理」（コラム10節）

- **問題**：罪名の振り分けは法的評価そのもの。単独のサービスとして掲げると**鑑定**に近づく。
- **修正後**：「**告訴状に記載する事実の整理**（いつ・どこに・何を書かれたか）」——事実の整理であることを明示。

### 3. 「一度ご相談ください」（コラム10節ほか）

- **問題**：法律相談の受任と読める。
- **修正後**：「**告訴状の作成についてご相談ください**」と目的語を必ず付ける。以後、原稿では「相談」を単独で使わない。

### 4. 「削除依頼の進め方のご案内」（コラム10節）

- **問題**：削除依頼の**代行**まで含むと誤解される可能性。
- **修正後**：「法務省が公開している手引き・テンプレートのご案内（**削除依頼の代行は行っておりません**）」と、できないことを明記。

### 5. 「活動名で仕事をしている方ほど特定されやすい。ご相談ください」（旧・短文案）

- **問題**：個別事案について成立し得るという評価を示したうえで受任を促す形になっていた。
- **対応**：短文案そのものを廃止（今回の方針変更）。同定可能性の話は、長文の中で一般論として扱う。

## 修正せず残した表現と、その理由

| 表現 | 判断 |
|---|---|
| 「告訴状の作成をお手伝いしています」 | 行政書士法1条の2の範囲内。問題なし |
| 「開示請求・損害賠償請求の代理、示談交渉は弁護士の業務です」 | **できないことの明示**。むしろ積極的に残すべき記述 |
| 「法務局は開示請求の代行はできません」 | 公表資料に基づく事実。法務局の業務範囲の説明であり問題なし |
| 条文の引用・解説 | 一般的な情報提供。個別事案への当てはめをしていないため問題なし |
| 「一般に説明されています」（伝播性理論・同定可能性） | 断定を避けた一般論の紹介。この表現のまま維持すること |

## 今後の原稿で守るルール

1. **個別事案の当否を断定しない。**「〜に当たります」ではなく「〜に当たり得ます」「一般に説明されています」を使う。
2. **「相談」には必ず目的語を付ける。**「告訴状の作成について」「書類の書き方について」。
3. **代理・交渉・請求の主語を事務所にしない。**削除依頼も開示請求も、主語はご本人か弁護士。
4. **できないことを毎回書く。**開示請求・損害賠償請求の代理、示談交渉は弁護士業務である旨を、記事の終盤に必ず入れる。
5. **「無料相談」「必ず削除できます」といった断定的な効果保証は書かない。**

## 併せて確認したい点（弁護士法以外）

- **景品表示法・行政書士会の広告規制**：「必ず」「確実に」といった表現は使っていません。
- **著作権**：条文は著作権の対象外（著作権法13条1号）、官公庁資料は出典明記のうえ利用。いずれも出典URLを併記済み。
- **依頼者の情報**：実際の事案・依頼者に触れた記述はありません。事例はすべて公表資料か、一般的な例示です。
